# 连击伤害公式

本文说明 `PlayerFight.ExcuseFightDamage` 中连击技能的伤害计算流程。连击技能由 `Skill.isComboSkill(actor, fightContext.skillId)` 判定。

## 计算流程

### 1. 基础伤害

连击分支不使用普通技能的攻击力上下限，而是直接将攻击者的力量、智力、敏捷相加后除以 2：

```text
D0 = (力量 + 智力 + 敏捷) / 2
```

代码对应：`config/天使之战_v1.0.0.0/meta/userapi/lua/fight/PlayerFight.lua` 中连击分支。

### 2. 命中与低命中率修正

攻击未命中时，函数直接返回未命中结果，伤害为 0。若命中成功且战斗上下文被标记为低命中率，则基础伤害乘以 20%：

```text
D1 = D0 × 0.2    （低命中率且命中）
D1 = D0          （其他命中情况）
```

`selectHitRate` 在攻击命中率不高于目标防御率时会标记低命中率，并将命中概率设为 30%；但玩家攻击怪物时，这种情况会直接判定未命中，不会进入 20% 伤害计算。

### 3. 护盾处理

连击伤害经过低命中率修正后，进入护盾处理。护盾处理前的值为 `D1`。

#### 玩家攻击玩家

目标有 SD 且攻击没有成功无视 SD 时，按以下比率计算 SD 吸收量：

```text
SD比率 = 0.9 + 目标 adbilvRate - 攻击者 SDsubRate
计划吸收量 = D1 × SD比率
实际吸收量 = min(计划吸收量, 目标当前SD)
护盾后伤害 = D1 - 实际吸收量
```

未破盾时，SD 吸收量会向下取整；破盾时，吸收量最多为目标当前 SD。目标没有 SD，或攻击成功无视 SD 时，伤害不因 SD 减少。

#### 玩家攻击怪物

满足怪物护盾条件时，代码尝试使用下面的公式增加伤害：

```text
护盾后伤害 = D1 + (攻击者最大攻击力 × 0.3)
               + (攻击者最大SD - 怪物 hudunValue) × 5
```

条件是怪物 `hudunValue >= 1` 且攻击者 `maxSD >= hudunValue`；不满足时伤害保持为 `D1`。

**实现注意：** `AGAndSD.calSDMonsterDeduction(caster, target, targetHurt)` 函数内部引用了未在该函数中定义的全局变量 `actor`，而不是参数 `caster`。因此该路径的职业和最大攻击力读取可能依赖全局环境；若 `actor` 不存在或不正确，实际结果可能异常。公式表达的是当前代码意图，运行时应核对这处变量引用。

#### 其他攻击者/目标组合

`calShild` 仅对玩家攻击玩家、玩家攻击怪物调用上述护盾逻辑；其他组合保持伤害不变。

### 4. 最终结果与取整

护盾处理后的伤害作为连击结果输出。结果字段按以下方式设置：

```text
targethurt     = ceil(护盾后伤害)
targethurtshow = ceil(护盾后伤害)
hurttype       = 301（连击）
repeat         = 1
comboskill     = true
```

因此通常情况下的总公式为：

```text
最终显示伤害 = ceil(护盾处理(D0 × 命中伤害系数))
命中伤害系数 = 0.2（低命中率但命中）或 1（其他命中情况）
```

未命中时不执行后续伤害公式，返回伤害 0。

## 计算示例

假设攻击者力量为 1000、智力为 600、敏捷为 400：

```text
D0 = (1000 + 600 + 400) / 2 = 1000
```

若属于低命中率但本次命中：

```text
D1 = 1000 × 0.2 = 200
```

之后再按目标类型进行护盾处理，并将护盾处理后的结果向上取整，得到最终显示伤害。

## 普通技能公式不适用于连击分支

连击分支不会继续执行普通技能伤害计算，因此不会在基础伤害上叠加以下普通技能逻辑：攻击力上下限随机值、目标防御扣减、技能攻击力/倍率、普通技能智力倍率，以及卓越、幸运、无视防御、双倍、致命一击等分支。
